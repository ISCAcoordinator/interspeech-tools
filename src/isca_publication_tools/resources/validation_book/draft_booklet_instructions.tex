\subsection*{Important caveats}
\hypertarget{section:caveats}
The dates and times for the scientific sessions, and the papers to be presented in each session, are firm and unlikely to undergo major changes.
However, minor changes \textit{are} possible, in which case the Technical Programme Committee Chairs will contact the authors of affected papers.

\noindent This booklet lists all full papers accepted for Interspeech 2025.
However, a paper will only appear in the final proceedings and be presented at the conference if:
\begin{enumerate}
\item it is covered by at least one author \textbf{registering} for the conference, and
\item a \textbf{satisfactory} Camera Ready manuscript is submitted, and
\item no \textbf{ethics} violations are discovered.
\end{enumerate}

This booklet is a draft that is likely to contain errors.
We ask the authors of each paper to check their information and, if any errors are spotted, to fill out the dedicated form: \url{https://forms.gle/2ukY8NV9U7PFL8R38}.
If you are unable to access the form and wish to report an error please email \url{publication@interspeech2025.org} with the information.

\begin{itemize}
    \item The title should not be in uppercase, and each title has been updated to fit this requirement
    \item Each author and affiliation has to be written using the Latin alphabet
    \item The format of each author is as follows: \verb|"First_Name {Middle_Initial] {Last Name} (Affiliations)"|
    \item The curly \verb|{ }| and round \verb|( )| brackets are mandatory elements - the square brackets are used to ensure that composed first names and composed last names are distinguishable
    \item The \verb|Middle_Initial| is optional (multiple middle initials can be used e.g. \verb|Julia [A.C.] {Smith}|)
    \item If an author was not registered on CMT their affiliation was not processed during the meta-data generation so please provide it here.
    \item For each affiliation, please ensure to have the following format: \verb|"Institute{, country}"| (with the country part optional.
    Please use a short version of the affiliation.
    For example:

    \verb|"Department of Phonetics, University of Helsinki, Finland"|

    should become

    \verb|"University of Helsinki, {Finland}"|
    \item multiple affiliation are separated with \enquote{; }
    \item each author is separated with \enquote{; }
    \item Here is an example of a full corect author list: {\normalfont\textit{Sébastien \{Le Maguer\} (University of Helsinki, \{Finland\}; Trinity College Dublin \{Ireland\}); Gwénolé \{Lecorvé\} (Orange Research, \{France\}); Damien \{Lolive\} (IRISA, Université Bretagne Sud, \{France\}); Naomi \{Harte\} (Trinity College Dublin, \{Ireland\}); Juraj \{Šimko\} (University of Helsinki, \{Finland\}) }}
\end{itemize}

\subsection{Your name appears multiple times in the index}

If you realize your name appears multiple time, this is likely due to the fact that different emails or IDs have been used to identify you. In this case only, please send an email to \url{publication@interspeech2025.org} indicating, your name, email and the list of paper IDs that you authored.
